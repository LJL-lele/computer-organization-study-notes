## 使用方法

- EMMX 源文件可在支持该格式的思维导图软件中打开，继续展开和编辑分支。
- 7 份 PDF 合计 148 页，保留 531 张内嵌图。可点击首页目录跳转，按 Ctrl+F 搜索正文。内嵌图里的文字可以放大查看。
- 55 张图文配图来自各章原导图，包含总览和局部放大图。指令系统和中央处理器使用原文件夹中的原图 PDF，其余章节按 EMMX 的布局导出。
